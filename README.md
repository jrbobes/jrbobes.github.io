# jrbobes.github.io

🎮 Personal landing page and portfolio for jrbobes

## Features

- **Attractive Modern Design**: Gradient background with smooth animations and responsive layout
- **Space Shooter Game**: An interactive arcade-style game built with vanilla JavaScript
- **Portfolio Display**: Showcase your GitHub and projects
- **Mobile Responsive**: Fully optimized for all screen sizes

## Quick Start

This repository is automatically deployed as a GitHub Pages site at: https://jrbobes.github.io

### Game Controls

- **Arrow Keys or A/D**: Move left and right
- **Spacebar**: Shoot
- **Start Game**: Begin playing
- **Pause**: Pause/resume game
- **Reset**: Clear the game state

### Game Mechanics

- Defend against incoming enemies
- Your score increases by 10 points per enemy destroyed
- Each wave gets progressively harder
- Game ends when you lose all 3 lives
- Enemies that reach the bottom cost you a life

## Customization

You can customize the landing page by editing `index.html`:

- **Colors**: Change the gradient colors in the `<style>` section
- **Game Difficulty**: Adjust `gameState` variables like `enemySpeed` and `shootSpeed`
- **Content**: Update the hero section text and links
- **Social Links**: Add your GitHub profile URL and other social media

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (no frameworks or dependencies)
